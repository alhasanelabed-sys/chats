# حاضر 1.3.0 — واجهة التشغيل التجريبي

[تنزيل البرنامج مباشرةً (ZIP)](https://raw.githubusercontent.com/alhasanelabed-sys/chats/codex/attendance-1.3.0/attendance-pro/1.3.0/iug-attendance-pro-1.3.0.zip) · [بصمة SHA-256](iug-attendance-pro-1.3.0.zip.sha256)

## التشغيل التجريبي من الواجهة

1. استخرج ZIP كاملاً، ثم افتح `start.bat` داخل مجلد `iug-attendance-pro`. يُحدّث متطلبات البرنامج عند الحاجة؛ التثبيت الأول يحتاج إنترنت.
2. ادخل بحساب مدير النظام. للتثبيت الجديد، كلمة مرور `admin` الأولية في `initial_admin_password.txt` داخل مجلد البيانات، ويلزم تغييرها.
3. افتح **النظام ← التشغيل التجريبي**. أدخل الموظفين والأجهزة والأيام وتكرارات القياس، أو اختر **10,000 موظف · 20 جهازاً** لتجربة 30 يوماً و600,000 حركة.
4. اختر تصدير CSV ومحاكاة الاستقبال المتزامن، ثم اضغط **ابدأ التجربة**. تظهر مراحل التشغيل والنتائج وأزمنة التقارير وعينة البيانات. يمكن تنزيل JSON وCSV، أو إلغاء التجربة وحذف نتائجها.

خيار إيقاف الكتابة على أجهزة التشغيل محدد افتراضياً: يحفظ `tcp.write_back=false` في البرنامج الرئيسي ويتركه مطفأً بعد التجربة. إزالة العلامة تترك القيمة الحالية كما هي ولا تفعّل الكتابة. التجربة نفسها تستخدم قاعدة مؤقتة وأجهزة محاكاة مستقلة، ولا تضيف موظفين أو حركات إلى سجلات التشغيل.

عند تحديث تثبيت قائم: أوقف البرنامج وخذ نسخة احتياطية، ثم استخدم ملفات البرنامج الجديدة مع مسار البيانات الحالي. لا تستبدل مجلد بيانات المؤسسة.

## التحقق

اجتاز الإصدار **330 اختباراً**، وتجربة 10,000 موظف و20 جهازاً محاكياً و600,000 حركة عبر API التجارب، مع تنزيل 600,001 صف CSV. نجح فحص المتصفح العربي والإنجليزي والهاتف، والتنزيل الفعلي والإلغاء والحذف وعزل البيانات. فُحصت بصمات جميع الملفات وسلامة ZIP، وشُغّلت تجربة من نسخة مستخرجة نظيفة.
