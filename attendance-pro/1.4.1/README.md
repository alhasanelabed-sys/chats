# حاضر 1.4.1 — اتصال الأجهزة وحركات اليوم والطباعة الكاملة

[تنزيل البرنامج ZIP مباشرة](https://raw.githubusercontent.com/alhasanelabed-sys/chats/04dd0c57fdf53c76842cc8c7bdd6f7416fa24bdb/attendance-pro/1.4.1/iug-attendance-pro-1.4.1.zip) · [المصدر](source/iug-attendance-pro/) · [دليل الإصدار](docs/دليل_الإصدار_1.4.1.md) · [تقرير التحقق](docs/تقرير_التحقق_1.4.1.md) · [المقارنة بالسوق](docs/مقارنة_السوق_1.4.1.md)

- اتصال الأجهزة يعتمد النبضات والقراءة الناجحة، بما فيها قراءة الساعة، دون انتظار حركة جديدة. القراءة فقط لا تجعل الجهاز غير متصل.
- المراقبة تعرض كل الحركات المحفوظة لليوم من 00:00 حسب توقيت المؤسسة. يطلب البرنامج سجلات اليوم عند بدء الاتصال وإعادته؛ توضح الواجهة اكتمال القراءة أو جزئيتها وفق البيانات المستلمة فعلياً.
- الأجهزة الافتراضية في بيئة التدريب المعزولة متصلة افتراضياً بالبرتقالي، مع حظر الاتصال بالأجهزة المادية.
- جميع أعمدة الشهر في عرض صفحة واحدة، مع صفوف الموظفين على صفحات متتابعة وتكرار العناوين، واختيار A4/A3 وعمودي/أفقي. صور المراقبة صغيرة وواجهة عربية وإنجليزية تتكيف مع النافذة الضيقة.

نجحت **473 اختباراً** على المصدر النهائي، وفحص متصفح من 14 سيناريو، واختبار الحجم لـ10,000 موظف و20 جهازاً محاكياً و600,000 حركة مع التصدير الكامل وإعادة رفع دون تكرار. فحص مستقل يشمل 31 يوماً و37 عموداً دون قص أفقي. الأدلة في `docs/verification`.

للتحديث: خذ نسخة احتياطية، أوقف الخادم السابق، واستعمل البرنامج الجديد مع بيانات المؤسسة الحالية. شغل `desktop.bat` داخل مجلد البرنامج لنافذة Windows عبر Edge/Chrome، أو `start.bat` للمتصفح. اترك الكتابة على الأجهزة مطفأة للحضور فقط.
