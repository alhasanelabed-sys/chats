# حاضر 1.2.0 — حزمة الحضور

[ملف البرنامج ZIP](iug-attendance-pro-1.2.0.zip) · [بصمة SHA-256](iug-attendance-pro-1.2.0.zip.sha256)

## التنزيل والتشغيل

1. افتح ملف ZIP من الرابط أعلاه واضغط **Download raw file** في GitHub.
2. استخرج جميع الملفات إلى مجلد مستقل؛ لا تشغّل البرنامج من داخل ZIP.
3. في ويندوز، افتح `start.bat` داخل المجلد المستخرج `iug-attendance-pro`. يثبّت Python والمتطلبات عند الحاجة، ويحتاج إنترنت في أول إعداد.
4. استخدم `admin` وكلمة المرور الموجودة في `initial_admin_password.txt` داخل مجلد البيانات، ثم غيّرها فوراً. ابدأ بإذن الكتابة إلى الأجهزة مطفأ.

عند تحديث تثبيت قائم، خذ نسخة احتياطية من البيانات أولاً؛ لا تستبدل مجلد بيانات المؤسسة.

## التحقق ونطاق الاستخدام

الحزمة للحضور فقط، حسب احتياج 10,000 موظف و20 جهاز ZKTeco SpeedFace V5L. اجتازت **281 اختباراً** واختبار حجم اصطناعياً بـ600,000 حركة. فُحصت سلامة ZIP وكل ملفات بيان الإصدار، وشُغلت نسخة مستخرجة نظيفة.
