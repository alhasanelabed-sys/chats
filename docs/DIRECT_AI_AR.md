# التحليل والترجمة من الهاتف — مجلس 0.5

هذا دليل تاريخي للإصدار 0.5. الإصدار 0.6 يعتمد خدمة سحابية مُدارة ولا يطلب هذه المفاتيح من المستخدم؛ راجع [دليل التفعيل الحالي](MANAGED_CLOUD_AR.md).

اختر Gemini أو OpenAI في «الإعدادات»، واحفظ مفتاح API مرة واحدة. بعدها يُحلّل التطبيق التسجيل ويعيد المحضر إليه تلقائيًا، ويمكن إعادة تلخيص النص المصحح وترجمته من داخل التطبيق. لا تحتاج تشغيل خادم أو إدخال عنوانه لهذا المسار.

## الإعداد أول مرة

1. اختر Gemini، وهو الافتراضي، أو OpenAI.
2. افتح [مفاتيح Google AI Studio](https://aistudio.google.com/apikey) أو [مفاتيح OpenAI](https://platform.openai.com/api-keys)، وأنشئ مفتاحًا لحسابك بحسب شروط المزود وتوافر الخدمة في بلدك.
3. أدخل المفتاح في حقل المفتاح داخل التطبيق، ثم احفظ الإعدادات. لا ترسله في محادثة ولا تحفظه في مستودع أو ملف محضر. يحفظه التطبيق مشفرًا باستخدام AES-GCM ومفتاح في Android KeyStore.
4. اضغط «اختبار الاتصال». يفحص هذا الإجراء الوصول إلى المزود دون رفع تسجيل، ولا يثبت وجود رصيد كافٍ أو نجاح تحليل اجتماع طويل.
5. سجّل اجتماعًا أو استورد M4A أو MP3 أو WAV، ثم اضغط «إعداد المحضر والملخص». راجع تأكيد الإرسال للمزود المختار قبل المتابعة.

المفتاح خاص بحساب API. الاشتراك الاستهلاكي في ChatGPT أو Gemini لا يضمن رصيد API لهذا التطبيق. قد تحتاج تفعيل الفوترة أو الالتزام بحصة مجانية إن كانت متاحة؛ راجع لوحة حساب المزود. يدعم بعض العملاء تسجيل الدخول بحساب ChatGPT في نطاقات محددة، لكن مسار رفع الصوت والتفريغ التلقائي المستخدم هنا يعتمد على مفتاح API.

## ماذا يرسل التطبيق؟

| العملية | البيانات المرسلة بعد الموافقة | النتيجة |
| --- | --- | --- |
| تحليل اجتماع عبر OpenAI | تسجيل الاجتماع، عنوانه، وحتى أربع عينات مسماة محفوظة إذا أضفتها | نص حسب المتحدثين ثم محضر عربي، مع مطابقة العينات إذا نجحت |
| تحليل اجتماع عبر Gemini | تسجيل الاجتماع وعنوانه؛ لا تُرسل عينات الأصوات المسماة | نص حسب تقدير المتحدثين ثم محضر عربي، دون مطابقة أسماء بالعينات |
| إعادة التلخيص | النص الحالي وأسماء المتحدثين والأوقات ومعرفات المقاطع | محضر جديد مبني على التصحيحات، دون رفع الصوت مرة أخرى |
| الترجمة | النص والمحضر وأسماء المتحدثين والأوقات ومعرفات المقاطع | ترجمة مرتبطة بالأصل، دون إعادة رفع الصوت |

لا يؤدي بدء التسجيل أو استيراد ملف أو حفظ محضر إلى رفع تلقائي. تبقى الملاحظات المحلية الخاصة بالتجارب وفك الترميز والمراجعة خارج طلبات تحليل النص. لا تدخل مفاتيح API في المحضر أو تصدير JSON أو PDF.

يدعم التطبيق ترجمة النص والمحضر إلى الإنجليزية والفرنسية والألمانية والإسبانية والتركية والعبرية والروسية واليونانية والأوكرانية والصينية والفارسية والأوردو. تُحفظ الترجمة لكل لغة، وتُعلّم للمراجعة إذا تغير المصدر. يقدّر التحليل لغة كل مقطع ووضوح نصه؛ راجع النص غير المفهوم، ولا تعتبره دليلًا تلقائيًا على تشفير.

## الفرق بين مساري الصوت

OpenAI يستخدم `gpt-4o-transcribe-diarize` للتفريغ وفصل المتحدثين، مع دعم حتى أربع عينات معروفة. الأسماء الأخرى تظهر بأرقام إلى أن تصححها. يستخدم `gpt-4.1-mini` افتراضيًا لإعداد المحضر وإعادة التلخيص والترجمة.

Gemini يستخدم `gemini-3.8-flash` افتراضيًا لفهم الصوت وإنشاء النص المنظم، ثم إعداد المحضر والترجمة. فصل الأصوات هنا تقدير من نموذج عام ويحتاج مراجعة، ولا توجد مطابقة للعينات المسماة. لا يثبت الرقم المعطى لمتحدث أنه هوية بيومترية مستقرة عبر اجتماعات مختلفة.

تتيح الإعدادات المتقدمة تغيير اسم نموذج المحاضر لدى OpenAI أو نموذج Gemini إذا تغير توافره في حسابك. اختر نموذجًا يدعم الإمكانات المطلوبة؛ توافر النموذج وحصته وتسعيره تحكمه خدمة المزود. لا يغير اسم النموذج جودة ميكروفون الهاتف أو يضمن سماع صوت خارج قدرته الفيزيائية.

## الخصوصية والاحتفاظ

النسخة المحلية من التسجيل والعينات والمحاضر في مساحة التطبيق الخاصة، والنسخ الاحتياطي التلقائي معطل. يستخدم الاتصال المباشر HTTPS إلى واجهات المزود الرسمية. مفتاح API محفوظ مشفرًا على الجهاز، لكنه يظل سرًا يمنح الوصول إلى حسابك؛ يمكنك إلغاؤه من لوحة المزود إذا احتجت ذلك.

يستخدم مسار Gemini واجهة رفع الملفات ويُحاول حذف الملف المرفوع عند انتهاء المعالجة أو فشلها. قد يتعذر الحذف إذا انقطع الاتصال، وسياسة المزود للاحتفاظ والمعالجة والتسجيل تبقى سارية حتى عند نجاح الحذف. حذف الاجتماع داخل مجلس يحذف النسخة المحلية فقط. راجع [شروط Gemini API](https://ai.google.dev/gemini-api/terms) و[إرشادات بيانات OpenAI API](https://platform.openai.com/docs/guides/your-data) للحساب الذي تستخدمه.

أعلم المشاركين بالتسجيل واستخدام خدمة معالجة خارجية. اقرأ التأكيد قبل الإرسال، وراجع الأسماء والنص والمواعيد والمسؤولين قبل اعتماد المحضر أو مشاركته.

## عند ظهور خطأ

- **مفتاح ناقص أو مرفوض:** احفظ مفتاح المزود المختار وتحقق من صلاحياته في لوحة الحساب. مفتاح Gemini لا يعمل مع OpenAI والعكس.
- **حصة أو رصيد غير كافٍ:** راجع الفوترة وحدود الاستخدام لدى المزود؛ اختبار الاتصال لا يحجز رصيد التحليل.
- **نموذج غير متاح:** راجع النماذج المتاحة لحسابك وأدخل نموذجًا متوافقًا في الإعدادات المتقدمة.
- **ملف غير صالح أو كبير:** استخدم M4A أو MP3 أو WAV سليمة، بحد 24 مليون بايت و60 دقيقة. الاستيراد الناجح لا يثبت صلاحية المحتوى لدى كل مزود.
- **انقطاع أثناء المعالجة:** يبقى التسجيل المحلي؛ يمكنك إعادة المحاولة بعد استعادة الشبكة. قد تحتسب الخدمة رسوم الطلب الذي نفذته قبل الانقطاع، ولا يعيد التطبيق إرساله تلقائيًا.

لمن لديه خادم مجلس سابق، يظل خيار الخادم المتقدم متاحًا، مع رابط HTTPS ورمز الوصول الخاص به. هذا الخيار لا يلزم لاستخدام Gemini أو OpenAI مباشرة؛ راجع [دليل الخادم](../backend/README.md) فقط إذا اخترته.

## حدود الإثبات

أمثلة المختبر ومحاكاة دخول المتحدثين تعتمد على بيانات مرجعية مصطنعة. ليست تفريغًا لتسجيلك أو برهانًا على التعرف الآلي أو فك شيفرة مجهولة. واختبارات التطبيق بمحاكاة استجابات المزود لا تقيس دقة العربية أو اللغات الأخرى، أو الفصل عند التداخل والبعد والضوضاء. يلزم تسجيل واقعي ومراجعة بشرية وقياس مشترك قبل إعلان تفوق على برامج عالمية.

المراجع الفنية: [تفريغ OpenAI](https://developers.openai.com/api/docs/guides/speech-to-text)، [فهم الصوت في Gemini](https://ai.google.dev/gemini-api/docs/audio)، و[ملفات Gemini](https://ai.google.dev/gemini-api/docs/files). قد تتغير واجهات الخدمة والنماذج وسياساتها بعد إصدار التطبيق.
