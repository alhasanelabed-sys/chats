# مجلس — نموذج تطبيق أندرويد للاجتماعات

تطبيق عربي أصلي يسجّل اجتماعًا، ويحفظه محليًا، ثم يرسل التسجيل بعد تأكيد واضح إلى OpenAI أو Gemini لإعداد نص حسب المتحدثين ومحضر وملخص. تضيف النسخة 0.5 الاتصال المباشر من الهاتف والتحليل وإعادة التلخيص والترجمة دون إدخال عنوان خادم. تحتاج إعداد مفتاح API مرة واحدة؛ لا توجد بعد قياسات لدقة الصوت على هاتف حقيقي أو مقارنة جودة فعلية بين المزودين.

## تنزيل ملف التثبيت

[تنزيل majlis-debug.apk مباشرة](https://raw.githubusercontent.com/alhasanelabed-sys/chats/refs/heads/app/majlis-android/downloads/majlis-debug.apk?v=0.5). هذا رابط عام لملف APK داخل فرع التطبيق، ولا يحتاج تسجيل الدخول إلى GitHub. ثبّت الملف على هاتف أندرويد 8.0 فأحدث، وتحقق من رقم النسخة في الإعدادات؛ لا يتغير الملف العام إلا بعد نجاح فحوص البناء والنشر. يمكن تجربة الاجتماع الجاهز وتسجيل الصوت دون إعداد مزود؛ التحليل الحقيقي يحتاج مفتاح الخدمة الموضح أدناه. يحتفظ فرع التطبيق بملف التثبيت، بينما تبقى نسخ GitHub Actions الإضافية متاحة 14 يومًا وتتطلب تسجيل الدخول.

## وظائف النموذج

- واجهة عربية من اليمين إلى اليسار، وتسجيل AAC/M4A حتى 60 دقيقة من الصوت الفعلي، بترميز 48 kbps وقناة واحدة و32 kHz.
- تسجيل ظاهر بإشعار يتيح الإيقاف المؤقت والمتابعة والإنهاء. يتوقف عداد الوقت أثناء التوقف المؤقت، ويستمر التسجيل عند قفل الشاشة. في أندرويد 13 فأحدث يُطلب إذن الإشعارات.
- استيراد M4A أو MP3 أو WAV من منتقي ملفات النظام إلى مساحة التطبيق الخاصة، حتى 24 مليون بايت و60 دقيقة. يتحقق التطبيق من الحجم والمدة قبل الرفع؛ الاستيراد نفسه لا يرفع شيئًا.
- تسجيل عينة مدتها 5 ثوانٍ باسم كل مشارك، بموافقته، حتى أربعة مراجع صوتية. العينة محفوظة على الجهاز؛ لا توجد قاعدة بيانات بصمات بيومترية.
- بعد انتهاء التسجيل: تفريغ متعدد اللغات وفصل المتحدثين ومحضر عربي. يدعم مسار OpenAI إرسال حتى أربع عينات لربط الاسم بالعينة إذا طابقها النموذج. يفصل مسار Gemini المتحدثين بتقدير النموذج دون إرسال هذه العينات أو مطابقة الأسماء بها. الأصوات الأخرى تُرقّم ويمكن تصحيح أسمائها، بما فيها من تكلم بعد انضمامه لاحقًا.
- ملخص، نقاط نقاش، قرارات، مهام ومسؤولون ومواعيد إن وردت، وأسئلة مفتوحة. لكل قرار ومهمة مراجع إلى مقاطع النص.
- تعديل اسم المتحدث ونص كل مقطع ونسبته إلى أحد المشاركين، مع إبقاء الوقت ومعرفات الأدلة. تصحيح النص يعلّم المحضر القديم بأنه يحتاج إعادة تلخيص.
- إعادة تلخيص النص المصحح بموافقة منفصلة لإرسال النص والأسماء؛ لا تعيد رفع الصوت أو تفريغه، وتستبدل المحضر والمهام السابقة.
- تعديل الملخص محليًا، وتعليم المهام المكتملة، والبحث العربي في المحاضر والنص، والاستماع من وقت المقطع أو دليل القرار.
- تصدير PDF عربي متعدد الصفحات وJSON ونص عبر منتقي حفظ النظام، ومشاركة المحضر، وحفظه وحذفه مع الصوت المرتبط.
- اختيار Gemini أو OpenAI من الإعدادات، وحفظ مفتاح API مشفرًا باستخدام Android KeyStore. فحص اتصال المزود من الإعدادات دون إرسال صوت؛ لا يثبت رصيد الحساب أو جودة التحليل. يبقى خيار خادم مجلس متاحًا للإعدادات السابقة.
- ترجمة النص والمحضر إلى 12 لغة: الإنجليزية والفرنسية والألمانية والإسبانية والتركية والعبرية والروسية واليونانية والأوكرانية والصينية والفارسية والأوردو، بموافقة إرسال النص والأسماء إلى الخدمة. تبقى المقاطع ومعرفاتها وأوقاتها مرتبطة بالأصل، وتُعلّم الترجمة للمراجعة إذا تغير المصدر.
- تفريغ متعدد اللغات بتحديد تلقائي من المزود، ومحضر عربي. لكل مقطع تقدير للغة ووضوح النص يرتبط بمتحدثه ووقته. النص غير المفهوم يوسم للمراجعة؛ لا يستنتج التطبيق وجود تشفير. يفك محليًا نصوص Base64 وHex ومورس وROT13 وقيصر عند تحديد الطريقة والإزاحة، ويحفظ النص غير القابل للفك بلا تخمين. يمكن للمستخدم توثيق تسمية «مرمز/مشفر» بنفسه.
- تجربة قياس تحفظ الهاتف وظروف التسجيل وزمن المعالجة، وتحسب محليًا WER وCER وتصحيحات إسناد المتحدثين مقارنة بالنسخة الأصلية، بعد تأكيد مراجعة المستخدم للتسجيل كاملًا. يصدّر JSON الأصل والمرجع للتحقق من الحساب. انظر [طريقة القياس وحدودها](docs/MEASUREMENT_PROTOCOL_AR.md).
- مختبر مدمج بأربع مجموعات بيانات مصطنعة: ستة متحدثين بمستويات قرب رقمية وعودة للكلام، وثماني لغات، وضوضاء متعددة، ونصوص مرمزة وأخرى غير مفهومة. محاكاة قائمة المتحدثين تتبع المرجع المعطى ولا تمثل تعرفًا آليًا. ملفات صوت مولدة ومرجعها في [downloads/fixtures](downloads/fixtures)؛ انظر [دليل التجارب](docs/FIXTURES_AR.md).
- اجتماع تجريبي معلّم بوضوح يمكن عرضه دون خادم أو اتصال أو مفتاح خدمة. محتواه مثال، وليس تحليلًا لتسجيل المستخدم.

[تنزيل حزمة الصوت التجريبي ومرجعه](https://raw.githubusercontent.com/alhasanelabed-sys/chats/refs/heads/app/majlis-android/downloads/fixtures/majlis-fixtures.zip). تضم ملف `manifest.json` الذي يبين اللغات المولدة فعليًا وأي مقاطع تجاوزتها أداة TTS، والمرجع المطابق لكل ملف.

فصل المتحدثين والتعرف على الاسم يجريان بعد انتهاء التسجيل، ولا يعرض النموذج تفريغًا أو مطابقة أصوات لحظية. الاسم الحقيقي لا يُستنتج من صوت مجهول؛ يدخله المستخدم مع العينة أو يصححه بعد التحليل. جودة التسجيل تتأثر بالمسافة والضوضاء والتداخل؛ استخدم ميكروفون اجتماعات للغرف الكبيرة. مراجعة المحضر مطلوبة قبل اعتماده.

## بناء تطبيق أندرويد

يتطلب Android 8.0 فأحدث (API 26). مشروع Android Studio موجود في `android/`، دون مكتبات أندرويد إضافية.

1. افتح مجلد `android` في Android Studio.
2. ثبّت Android SDK Platform 35 وBuild Tools 35.0.0، واسمح باستكمال اعتماديات Gradle.
3. ابنِ `app` بصيغة Debug، ثم ثبّته على هاتفك أو المحاكي.

يوجد مسار بناء من سطر الأوامر باستخدام SDK مثبت محليًا، موضح في `scripts/build-android.sh`. يكتب APK في `dist/majlis-debug.apk`. النسخة التجريبية تستخدم مفتاح debug محليًا، وليست إصدارًا للنشر في Google Play. أدوات SDK ومفاتيح توقيع debug لا تدخل في حزمة المصدر.

على فرع `app/majlis-android` يشغّل GitHub Actions بناء أندرويد واختبارات الساعة وعقود البيانات والخادم، ثم يفحص الواجهة على محاكي Android 15. يولد أيضًا صوتًا مصطنعًا بأداة TTS محلية ويختبر مراجع التجارب وأدوات فك الترميز. لا يستبدل ملف APK العام إلا بعد نجاح كل تلك المهام. يحتفظ Actions بأدلة المحاكي والنسخ الإضافية مدة 14 يومًا. لا تتطلب هذه الاختبارات مفاتيح مزودين، ولا تمثل تحليلًا أو ترجمة عبر حساب حي.

تستخدم عمليات البناء الآلية الحالية مفاتيح Debug مؤقتة؛ قد يلزم حذف النسخة السابقة لتثبيت 0.5، مما يمسح بياناتها. صدّر المحاضر المهمة قبل الحذف. انظر [ملاحظات الإصدار](docs/RELEASE_NOTES_AR.md).

## إعداد التحليل الحقيقي

1. افتح «الإعدادات» واختر Gemini، وهو الخيار الافتراضي، أو OpenAI.
2. أنشئ مفتاحًا في [Google AI Studio](https://aistudio.google.com/apikey) أو [لوحة OpenAI](https://platform.openai.com/api-keys)، ثم أدخله في التطبيق مرة واحدة واحفظه. لا ترسل المفتاح في محادثة أو تضعه في مستودع المشروع. يخزنه التطبيق مشفرًا باستخدام Android KeyStore.
3. استخدم «اختبار الاتصال»، ثم سجّل الاجتماع أو استورد ملفًا. بعد الإنهاء اضغط «إعداد المحضر والملخص» واقرأ تأكيد الإرسال للمزود المختار. تسجيل الصوت لا يرفعه تلقائيًا.
4. راجع النص وأسماء المتحدثين، وأعد تلخيص النص المصحح عند الحاجة. اختر لغة الترجمة داخل المحضر؛ يطلب التطبيق موافقة منفصلة لإرسال النص والأسماء، دون إعادة رفع الصوت.

قد تُحتسب رسوم على حساب صاحب المفتاح بحسب المزود والخطة. اشتراك ChatGPT أو Gemini الاستهلاكي لا يضمن رصيد API لهذا التطبيق. مسار التحليل الصوتي التلقائي هنا يستخدم مفتاح API، ولا يطلب منك تشغيل خادم. يوضح [دليل الربط المباشر](docs/DIRECT_AI_AR.md) الإعداد والخصوصية والفروق بين المزودين.

مع OpenAI، يمكن إضافة عينات المشاركين من تبويب الأصوات، بموافقتهم، لإرسالها مع الاجتماع. مع Gemini لا تُرسل العينات؛ تُراجع الأسماء وتُعدّل بعد التحليل. فصل المتحدثين تقدير قابل للخطأ في كلا المسارين، خصوصًا عند التداخل والبعد والضوضاء.

خيار «خادم مجلس» المتقدم متاح لمن يستخدم خدمة سابقة، لكنه ليس مطلوبًا للاتصال المباشر. لتشغيله اتبع [دليل الخادم](backend/README.md)، ثم أدخل رابط HTTPS ورمز `MAJLIS_ACCESS_TOKEN`. على المحاكي يمكن استخدام `http://10.0.2.2:8000` لخادم يعمل على الحاسوب المضيف. لم يُنشر خادم عام ضمن المشروع.

حذف عينة في التطبيق يحذف ملفها المحلي، وحذف اجتماع يحذف المحضر والصوت المرتبط. يوقف النموذج التسجيل المنقطع ويمنع عرضه كملف مكتمل بعد فقد العملية. لا يبدأ الميكروفون تلقائيًا بعد إعادة تشغيل التطبيق. النسخ الاحتياطي التلقائي معطل. يحاول مسار Gemini حذف الملفات المرفوعة عند انتهاء المعالجة، مع بقاء سياسة المزود للاحتفاظ بالبيانات سارية؛ حذف النسخة المحلية لا يحذف بيانات المزود تلقائيًا.

## التحقق وحدوده

```bash
cd backend
python -m unittest discover -s tests -v
python -m compileall -q app tests
```

اجتاز خادم 0.4 الموثق 51 اختبارًا باستخدام M4A وMP3 وWAV حقيقية مولدة ببرنامج FFmpeg، ومحاكاة مزود الخدمة عند حد HTTP فقط. تشمل المصادقة وحدود الحجم والمدة والعينات وظهور متحدث جديد والأدلة وإعادة التلخيص والترجمة وملاحظات اللغات وتنظيف الملفات وإيقاف التهيئة عند المهلة والإلغاء. لا تثبت هذه الاختبارات دقة النموذج في غرفة فعلية أو صحة الربط المباشر الجديد.

شملت فحوص 0.4 الموثقة 28 حالة لساعة التسجيل و26 سيناريو JVM للبيانات وHTTP محلي، و11 فحصًا لحساب القياس، و24 مجموعة لفك الترميز، و12 اختبارًا لمراجع التجارب وخلط الصوت، وفحص محاكي للتسجيل والمثال وتصحيح النص وحفظه وإعادة فتحه وتصدير PDF. هذه نتائج الإصدار السابق، وليست إثباتًا لاجتياز الربط المباشر في 0.5. يلزم أيضًا اختبار هاتف حقيقي: قفل الشاشة، أذونات مرفوضة، العينات، التداخل والبعد عن الميكروفون، وتحليل وترجمة فعليان.

اجتاز الإصدار 0.4 [تشغيل CI](https://github.com/alhasanelabed-sys/chats/actions/runs/38051866988): بناء وتوقيع APK، و152 حالة تحقق للخادم والساعة والبيانات والقياس والترميز والعينات، وفحص الواجهة على أندرويد 15. شمل الفحص 13 دورًا لقائمة المتحدثين، وفك مثال Base64 عربي، وحفظ النص غير القابل للفك وإعادة فتحه، وتسجيل AAC والإيقاف المؤقت وتصدير PDF. وُلّدت الملفات الصوتية بالفعل لمحاكي ستة أصوات بالعربية وثماني لغات في مجموعة أخرى؛ لا يثبت ذلك جودة التعرف أو الترجمة لدى المزود.

## المقارنة مع التطبيقات العالمية

راجع [المقارنة العربية الموثقة](docs/COMPETITOR_COMPARISON_AR.md) مع Otter وFireflies وNotta وPlaud. تستند إلى الوثائق الرسمية بتاريخ 10 أكتوبر 2026، وتصف وضع 0.4 وتفرّق بين دعم اللغة وقياس الدقة، وبين فصل المتحدثين والتعرف على أسمائهم. يزيل الربط المباشر في 0.5 شرط إعداد خادم للاستخدام الشخصي، لكنه لا يثبت تفوقًا في الدقة؛ التطبيقات التجارية توفر خدمات مُدارة وتكاملات فرق أوسع.

## ملفات المشروع

`fixtures/`: المراجع المصطنعة. `android/`: التطبيق الأصلي. `backend/`: خدمة المعالجة واختباراتها. `scripts/`: بناء التطبيق وفحص أدوات SDK. `dist/`: مخرجات المصدر والبناء. لا توجد مفاتيح خدمة أو حسابات جاهزة في المشروع.
